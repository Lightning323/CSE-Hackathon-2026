# Project Structure

Grid Quest is a Godot 4.7 (C#, Forward+) 2D game built for CSE Hackathon 2026.

```
grid-quest/
├── project.godot              # Godot project config (name, features, physics, rendering)
├── Grid Quest.csproj          # .NET 8 project (Godot.NET.Sdk 4.7.2)
├── Grid Quest.sln             # Solution file
├── icon.svg                   # Project icon
├── setup_mcp.sh               # Registers the Godot MCP server with opencode
├── AGENTS.md                  # Instructions for AI coding agents
├── docs/
│   └── project-structure.md   # This file
├── assets/
│   └── Cute_Fantasy_Free/     # "Cute Fantasy" free asset pack (see read_me.txt)
│       ├── Animals/           # Chicken, Cow, Pig, Sheep
│       ├── Enemies/           # Skeleton, Slime_Green
│       ├── Outdoor decoration/# Bridges, chests, fences, houses, trees
│       ├── Player/            # Player.png, Player_Actions.png (sprite sheets)
│       └── Tiles/             # Beach, cliff, farmland, grass, path, water tiles
├── level/
│   └── map.tscn               # Main gameplay map (root: Node2D "Map" with Player instance)
├── menus/
│   └── main_menu.tscn         # Main menu (root: Node2D "MainMenu" + CanvasLayer)
├── enemy/
│   ├── Enemy.cs               # Chases player, health bar, idle/walk animations
│   ├── Enemy.cs.uid           # Godot-generated script UID
│   └── enemy.tscn             # Enemy scene (CharacterBody2D + AnimatedSprite2D + HealthBar)
└── player/
    ├── Player.cs              # 8-direction movement, idle/walk/attack/death animations
    ├── Player.cs.uid          # Godot-generated script UID
    └── player.tscn            # Player scene (CharacterBody2D + AnimatedSprite2D + CollisionShape2D)
```

## Player

`Player.cs` builds its `SpriteFrames` at runtime from `Player.png` (32x32 frames, six columns):

| Row | Animation | Frames |
| --- | --- | --- |
| 0-2 | idle down / side / up | 6 |
| 3-5 | walk down / side / up | 6 |
| 6-8 | attack down / side / up | 4 |
| 9 | death | 4 |

Movement uses `move_left`, `move_right`, `move_up`, `move_down` (arrow keys) and the attack
action is bound to Space and J. Left is drawn by flipping the side animation. Diagonal input
moves at the same speed as cardinal input because `Input.GetVector` normalizes it.

## Enemy

`Enemy.cs` builds its `SpriteFrames` at runtime from `Enemies/Skeleton.png` (same 32x32 / 6x10
layout as the player). It chases the player, updates facing based on movement direction, and plays
`idle_*` / `walk_*` animations with the side animation flipped for left-facing movement.

## Notes

- `.godot/` is generated by the editor and ignored by git — do not edit it by hand.
- `.import` files are generated by Godot on asset import and should be committed.
- The asset pack is licensed for **non-commercial** use; see `assets/Cute_Fantasy_Free/read_me.txt`.
- Scenes use Godot 4.7 scene format (`uid=` attributes are managed by the editor).
- Custom C# scripts (e.g. `player/Player.cs`, `enemy/Enemy.cs`) target .NET 8 and live under the `GridQuest` root namespace.
